# Fonts

Committed so that examples and tests resolve fonts identically on every machine,
which is what `--strict-fonts` requires.

| File | Face |
|---|---|
| `Go-Regular.ttf` | Go Regular |
| `Go-Bold.ttf` | Go Bold |

Both are the Go fonts, by the Bigelow & Holmes / Go Authors, extracted from
`golang.org/x/image/font/gofont`. BSD 3-clause — see [LICENSE](LICENSE).
